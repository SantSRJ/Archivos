    1.1¿Qué es un archivo y para qué sirve?5 min

    Registros y campos

    Un archivo es un conjunto de elementos llamados registros, todos del mismo tipo. Cada registro reúne varios datos sobre un mismo sujeto (una persona, un producto). Cada uno de esos datos es un campo.

    legajoapellido y nombrenota
    123456Roma, Pablo Diego10
    123457Lezama, Luisa8

    En notas.txt, cada línea es un registro y cada dato separado por ; es un campo.

    ¿Por qué son útiles? Para persistir la información en el tiempo y para compartirla entre usuarios y aplicaciones.

    Nota para el docente

    Abrí notas.txt en el explorador y pedí que identifiquen en voz alta cuántos registros y cuántos campos tiene. Conectá con la matriz de la clase de listas: un archivo de texto con separador es, en el fondo, una matriz guardada en disco.

    Archivos de texto y binarios

    De texto

    Datos guardados como cadenas de caracteres. Se abren con cualquier editor (Bloc de notas, VS Code). Son el tema de hoy.

    Binarios

    Bytes que solo entiende un programa: imágenes, audio, ejecutables. Se abren con modo "b".

    Un archivo de texto plano no tiene formato (ni negrita ni colores), cada línea es un registro, su longitud es variable y por eso necesita un delimitador.

    Todo trabajo con archivos sigue tres pasos:

    1. Abriropen()
    2. Manipularwrite() · readline()
    3. Cerrarclose()

    1.2El delimitador de registro: \n4 min

    Lo que el archivo guarda en realidad

    Como las líneas tienen longitud variable, entre registro y registro hay un carácter especial: el salto de línea, que en Python se escribe \n. El editor lo muestra como “bajar de renglón”, pero en el archivo es un carácter más.

    Lunes\nMartes\nMiércoles\n

    Por eso, cuando leemos una línea, el \n viene incluido al final; y cuando escribimos, tenemos que agregarlo nosotros.

    Alerta de error típico: la última línea sin salto

    Muchos archivos, como semana.txt y notas.txt de esta clase, no tienen \n después del último registro. Si después agregás un registro en modo "a", queda pegado al anterior: JuevesViernes. Lo resolvemos en el ejercicio B1.

    # repr() muestra los caracteres "invisibles" de cada línea
with open("semana.txt", encoding="UTF-8") as archivo:
    for linea in archivo:
        print(repr(linea), "->", len(linea), "caracteres")

    2.1Apertura con open() y modos8 min

    open() devuelve un objeto archivo que guardamos en una variable. file es el nombre (con o sin ruta) y mode, el modo de apertura:

    ModoPara quéSi el archivo NO existeSi el archivo YA existe
    "r" (por defecto)LeerFileNotFoundErrorLo lee desde el principio

    2.2Rutas y la trampa de la barra invertida5 min

    ¿Dónde busca Python el archivo?

    Si no ponés ruta, Python busca el archivo en la misma carpeta del programa. Si ponés una ruta de Windows, cuidado: la barra invertida \ inicia secuencias de escape. En "c:\nuevo\datos.txt" el \n se convierte en un salto de línea y la ruta queda inválida.

    SoluciónEjemplo
    Doble barra invertida"c:\\nuevo\\datos.txt"
    Barra normal"c:/nuevo/datos.txt"
    Cadena cruda (raw)r"c:\nuevo\datos.txt"

    La materia recomienda no pedirle al usuario el nombre del archivo: es una decisión del programador.

    ruta_mal = "c:\nuevo\datos.txt"
ruta_doble = "c:\\nuevo\\datos.txt"
ruta_barra = "c:/nuevo/datos.txt"
ruta_cruda = r"c:\nuevo\datos.txt"

print(repr(ruta_mal))          # tiene un \n real adentro
print(ruta_mal)                # se "rompe" en dos renglones
print(ruta_doble == ruta_cruda)   # True: las dos son la misma ruta
print(ruta_barra)

open(ruta_mal, "wt")           # OSError: Invalid argument (en Windows)

    2.3Cierre seguro: try / except / finally6 min

    Todo archivo se debe cerrar

    Al cerrar con close() se graban los cambios pendientes y se libera el archivo para otros programas. Por eso el cierre suele ir en el finally, que se ejecuta pase lo que pase.

    Pero si open() falló, la variable nunca se creó y arch.close() lanza NameError. Por eso el material protege el cierre con un segundo try.

    Alerta de error típico: cerrar dentro del try

    Si el close() está al final del try y ocurre un error en el medio, el archivo queda abierto. En un programa que escribe, se pueden perder los datos que todavía no se grabaron en el disco.

    Nota para el docente

    Este patrón es largo a propósito: muestra todo lo que hay que cuidar. En el Módulo 3 aparece with, que hace lo mismo en una línea. Conviene que primero entiendan el problema que with resuelve.

    def abrirArchivo(arch):
    try:
        contenido = open(arch, "r", encoding="UTF-8")
        for linea in contenido:
            print(linea.strip())
    except FileNotFoundError:
        print("Error, el archivo no existe")
    except OSError:                  # incluye IOError y otros problemas del sistema
        print("Error, no se pudo abrir el archivo")
    finally:
        try:
            contenido.close()        # siempre debe cerrarse
            print("[archivo cerrado]")
        except NameError:            # open() falló: no hay nada que cerrar
            print("[no había nada que cerrar]")

abrirArchivo("semana.txt")
abrirArchivo("feriados.txt")

    Del error más específico al más general

    ExcepciónCuándo aparece
    FileNotFoundErrorEl archivo (o la carpeta) no existe al leer.
    IsADirectoryErrorLa ruta es una carpeta, no un archivo.
    PermissionErrorSin permisos: archivo de solo lectura, en uso, protegido.

    def ingresar_datos(archivo):
    try:
        arch = open(archivo, "w", encoding="UTF-8")
        legajo = input("Legajo (enter para terminar): ")
        while legajo != "":
            nombre = input("Nombre: ")
            arch.write(legajo + ';' + nombre + '\n')   # el \n lo agregamos nosotros
            legajo = input("Legajo (enter para terminar): ")
        print("Archivo creado correctamente.")
    except OSError as mensaje:
        print("No se puede grabar el archivo:", mensaje)
    finally:
        try:
            arch.close()
        except NameError:
            pass

    3.2Métodos de lectura y el simulador de readline()10 min

    ¿Qué métodos usamos en la materia?

    MétodoQué devuelveEn la materia
    arch.read()Todo el archivo en una cadenaNo aceptado: peligroso con archivos grandes
    arch.read(n)n caracteresNo aceptado
    arch.readlines()Una lista con todas las líneasNo aceptado: carga todo en memoria
    arch.readline()Una línea, o "" al finalAceptado
    for linea in archUna línea por vueltaAceptado

    La regla tiene una razón: un archivo puede tener millones de registros. Con readline() o for … in hay una sola línea en memoria por vez, sin importar el tamaño del archivo.

    El patrón de readline() tiene tres partes: una lectura antes del while, la condición while linea: (una cadena vacía es falsa) y una lectura al final del bloque.

    Alerta de error típico: olvidar la lectura al final del while

    Sin el último linea = arch.readline(), la variable nunca cambia y el bucle es infinito: procesa la primera línea para siempre. En la consola de esta página vas a ver el aviso Ejecución detenida.

    Alerta de error típico: strip() antes de la condición y las líneas vacías

    En A04 se hace arch.readline().strip(). Si el archivo tiene una línea en blanco en el medio, strip() la convierte en "" y el while termina antes de tiempo, sin leer el resto. Hacer el strip() adentro del bucle (como en A06) evita el problema.

    Simulador: ¿qué devuelve cada readline()?

    Elegí un archivo y tocá readline() varias veces. El cursor muestra dónde está parado Python; cuando llega al final, devuelve una cadena vacía y el while termina.

    def leerArchivo(archivo, modo):
    try:
        arch = open(archivo, modo, encoding="UTF-8")
        linea = arch.readline().strip()               # 1) primera lectura ANTES del while
        print(f'{"Legajo":10}{"Apellido y nombre":20}{"Nota":4}')   # Encabezados
        while linea:                                  # 2) mientras no sea cadena vacía
            leg, apenom, nota = linea.split(";")
            if int(nota) >= 7:
                print(f'{leg:10}{apenom:20}{nota:>4}')
            linea = arch.readline().strip()           # 3) leemos la línea siguiente
    except OSError:
        print("No se pudo leer el archivo")
    finally:
        try:
            arch.close()
        except:
            print("No se pudo cerrar el archivo")

    def mostrarCumpleanios(archivo, modo, mes, anioActual):

    Abrir, usar y cerrar solo

    with open(...) as file: abre el archivo y lo cierra automáticamente al salir del bloque, incluso si ocurre un error. Reemplaza todo el finally con el doble try.

    Sin witharch = open(...)try: ...finally:    try: arch.close()    except NameError: pass
    Con withwith open(...) as arch:    ...se cierra al terminar el bloque

    with no reemplaza al try: si el archivo no existe, open() sigue lanzando la excepción. Por eso A08 envuelve el with en un try.

    Después del with el archivo ya está cerrado. Un file.readline() fuera de la sangría lanza ValueError: I/O operation on closed file.

    def abrirArchivoWith(archivo, modo):

    4.1Otros formatos: un campo por línea y ancho fijo8 min

    Un campo por línea

    Cada empleado ocupa cuatro líneas: legajo, nombre, categoría y sueldo. Para leerlo hacen falta cuatro readline() por registro: un caso donde for … in no alcanza y conviene el control explícito.

    Ancho fijo (encolumnado)

    Cada campo ocupa siempre la misma cantidad de columnas, completando con espacios. Se graba con f-strings de ancho fijo (:06d, :<30) y se lee con slicing: linea[7:37].

    ÍndicesCampoFormato al grabarSlicing al leer

    Alta en append; baja y modificación con auxiliar

    En un archivo de texto no se puede borrar ni cambiar una línea “en el lugar”. Por eso cada operación tiene su técnica:

    OperaciónTécnica
    Create (alta)Abrir en "a" y escribir el registro nuevo al final.
    Read (listado)Recorrer con for … in o readline().
    Update (modificación)Copiar todo a un auxiliar, cambiando el registro buscado.
    Delete (baja física)Copiar todo al auxiliar excepto el registro a borrar.
    1Leer el original y escribir el auxiliarregistro por registro, aplicando el cambio
    2Cerrar los dosal salir del with
    3os.remove(original)borrar el archivo viejo
    4os.rename("auxiliar.txt", original)el auxiliar toma su nombre

    Así nunca se carga todo el archivo en memoria: funciona igual con 5 registros que con 5 millones.

    Alerta de error típico: renombrar antes de borrar

    En Windows, os.rename() falla con FileExistsError si el destino ya existe (en Linux y macOS lo reemplaza sin avisar). Por eso primero os.remove(original) y después os.rename(). La alternativa portable es os.replace("auxiliar.txt", original), que hace las dos cosas.

    Alerta de error típico: borrar o renombrar con el archivo abierto

    Si llamás a os.remove() dentro del with, el archivo todavía está abierto y Windows responde PermissionError: el proceso no tiene acceso al archivo porque está siendo utilizado. Primero se sale del with (se cierran los archivos) y después se borra y renombra.

    Nota para el docente

    Ejecutá los tres bloques en orden (alta, baja, modificación) con el explorador de la apertura abierto: vas a ver aparecer y desaparecer auxiliar.txt. Es la técnica que pide la tarea del proyecto final. El material menciona una carpeta CRUD_archivos; estos bloques son una versión propia de esta guía con la misma idea.

    def alta_producto(archivo, descripcion, precio):
    """Agrega un producto al final, con código autoincremental (A001, A002...)."""
    ultimo = 0
    try:
        with open(archivo, "r", encoding="UTF-8") as arch:    # 1) buscar el último código
            for linea in arch:
                linea = linea.strip()
                if linea:
                    codigo = linea.split(";")[0]               # "A005"
                    ultimo = max(ultimo, int(codigo[1:]))      # 5
    except FileNotFoundError:
        pass                                                   # sin archivo: arranca en A001
    nuevo = f"A{ultimo + 1:03d}"
    try:
        with open(archivo, "a", encoding="UTF-8") as arch:    # 2) agregar al final
            arch.write(f"{nuevo};{descripcion};{precio}\n")
        print("Alta:", nuevo, descripcion)
    except OSError as e:
        print("No se pudo grabar:", e)

    import os

def baja_producto(archivo, codigo_baja):
    """Baja física: copia todos los registros MENOS uno a un archivo auxiliar."""
    encontrado = False
    try:
        with open(archivo, "r", encoding="UTF-8") as original, \
             open("auxiliar.txt", "w", encoding="UTF-8") as aux:
            for linea in original:
                codigo = linea.split(";")[0]
                if codigo == codigo_baja:
                    encontrado = True              # este registro NO se copia
                else:
                    aux.write(linea)               # la línea ya trae su \n
    except OSError as e:
        print("Error al procesar:", e)
        return
    if encontrado:
        os.remove(archivo)                         # 1) borrar el original
        os.rename("auxiliar.txt", archivo)         # 2) el auxiliar pasa a ser el original
        print("Baja realizada:", codigo_baja)
    else:
        os.remove("auxiliar.txt")                  # nada cambió: descartar el auxiliar
        print("No existe el código", codigo_baja)

def modificar_precio(archivo, codigo_buscado, nuevo_precio):
    """Modificación: copia todo al auxiliar, cambiando solo el registro buscado."""

        print("Error al modificar:", e)

    4.3Recomendaciones de la materia5 min

    Buenas prácticas con archivos

    • No cargar todo el archivo en memoria: la ventaja de un archivo es justamente procesarlo de a un registro.
    • No abrir y cerrar el archivo por cada registro: los tiempos se disparan. Se abre, se procesa y se cierra.
    • Minimizar los recorridos: si con una pasada alcanza, no se lee dos veces.
    • En modo "r" el archivo tiene que existir; "w" y "a" lo crean.
    • No pedirle al usuario el nombre del archivo: lo decide el programador.
    • Capturar FileNotFoundError antes que OSError.

    ¿Por qué importa abrir una sola vez?

    Cada open() le pide al sistema operativo que busque el archivo, verifique permisos y prepare el acceso. Hacerlo una vez por registro multiplica ese costo por la cantidad de registros.

    Abre una vez por registrofor dato in datos:    with open(r, "a") as f:        f.write(dato)1.000 registros = 1.000 aperturas
    Abre una sola vezwith open(r, "a") as f:    for dato in datos:        f.write(dato)1.000 registros = 1 apertura

    def campo(texto):
    texto = str(texto)
    return f"{len(texto):02d}{texto}"

def siguiente(linea, pos):
    largo = int(linea[pos:pos + 2])            # 2 dígitos con el largo
    dato = linea[pos + 2:pos + 2 + largo]       # el campo propiamente dicho
    return dato, pos + 2 + largo

def grabarConLongitudVariable(archivo, modo):
    try:
        with open(archivo, modo, encoding="UTF-8") as arch:
            nombre = input("Nombre: ").strip()
            while nombre != "":
                legajo = int(input("Legajo: "))
                cat = input("Categoria: ").strip()
                while len(cat) != 1:
                    cat = input("Categoria: ").strip()
                sueldo = float(input("Sueldo: "))
                arch.write(campo(legajo) + campo(nombre) + campo(cat.upper()) + campo(sueldo) + "\n")
                nombre = input("Nombre: ").strip()
    except OSError:
        print("No se pudo grabar el archivo.")
    except ValueError:
        print("Dato numérico inválido: se cancela la carga.")

def cargarConLongitudVariable(archivo, modo):

    Corte de control: ventas por sucursal
     Nivel Dios
    
  
    ventas.txt tiene las ventas ordenadas por sucursal (sucursal;fecha;importe). En un solo recorrido con readline(), mostrá para cada sucursal la cantidad de ventas, el total y la venta más grande; al final, el total general y la sucursal que más vendió. Grabá el resumen en resumen_ventas.txt.
    Salida esperada
    Centro   ventas: 3  total: $ 35,500.50  máx: $15,000.00
Norte    ventas: 2  total: $ 15,300.00  máx: $ 9,900.00
Palermo  ventas: 3  total: $ 39,850.75  máx: $21,000.00
Sur      ventas: 1  total: $  3,300.00  máx: $ 3,300.00
Total general: $93,951.25
Sucursal que más vendió: Palermo ($39,850.75)
    
  
     Tu solución
    
  
    
  
     Ver pista
    Es el algoritmo clásico de corte de control: un while externo por sucursal y uno interno que avanza mientras la sucursal de la línea leída sea la misma. Cuando cambia, se “corta” y se informan los subtotales.
    
  
     Ver solución explicada
    1. Leé la primera línea antes de los bucles y separala en campos con una función leer(arch) que devuelva None al final.
    2. Bucle externo while reg is not None: guardá la sucursal actual e inicializá contadores.
    3. Bucle interno while reg is not None and reg[0] == actual: acumulá y leé el siguiente registro.
    4. Al salir del interno, la sucursal cambió: informá, acumulá al total general y comparalo con el máximo.
    5. Por qué no for … in: necesitamos leer “de adelanto” la línea que dispara el corte. Es el caso de uso de readline() que menciona la teoría.
    def leer(arch):
    """Devuelve (sucursal, fecha, importe) o None al final del archivo."""
    linea = arch.readline()
    while linea and not linea.strip():         # saltear líneas vacías
        linea = arch.readline()
    if not linea:
        return None
    suc, fecha, imp = linea.strip().split(";")
    return suc, fecha, float(imp)

total_general = 0
mejor_suc, mejor_total = "", -1
with open("ventas.txt", "r", encoding="UTF-8") as arch, \
     open("resumen_ventas.txt", "w", encoding="UTF-8") as res:
    reg = leer(arch)
    while reg is not None:                         # una vuelta por sucursal
        actual = reg[0]
        cant, total, maximo = 0, 0, 0
        while reg is not None and reg[0] == actual:    # mismas sucursal
            cant += 1
            total += reg[2]
            maximo = max(maximo, reg[2])
            reg = leer(arch)                       # lectura de adelanto
        # corte: cambió la sucursal (o terminó el archivo)
        print(f"{actual:<8} ventas: {cant}  total: ${total:>10,.2f}  máx: ${maximo:>9,.2f}")
        res.write(f"{actual};{cant};{total:.2f}\n")
        total_general += total
        if total > mejor_total:
            mejor_suc, mejor_total = actual, total

print(f"Total general: ${total_general:,.2f}")
print(f"Sucursal que más vendió: {mejor_suc} (${mejor_total:,.2f})")
